# Progress logs

Append-only English handoffs. Replaces Notion executor logs.

## How to append

1. Add `NNN-short-slug.md` (next integer, never overwrite).
2. Include: date, agent, current state, files, verification, blockers, next steps.
3. Point at the active `specs/NNN-slug/` when one exists.

Pre-SDD Notion summary (frozen): [`../progress_old/notion-extract.md`](../progress_old/notion-extract.md).
